📝 Quick Guide
✏️ Content Kaise Edit Karein?

Sidebar mein jo section edit karna hai usmein jao, changes karo aur "Save" button dabao. 2-3 minutes mein website update ho jayegi.

🖼️ Images Kaise Add Karein?

GitHub repo mein image upload karo (same folder mein). Phir Gallery ya Images section mein sirf file ka naam likho jaise: campus.jpg

📱 Applications Kahan Milenge?

Sidebar mein "Admissions" aur "Counsellings" section mein Google Sheet se data load hota hai. Refresh karne ke liye page reload karo.

🔑 Password Change Karein?

admin.html file mein ADMIN_PASSWORD variable dhundho aur apna naya password set karo.
